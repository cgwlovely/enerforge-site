Where the rules take it

The baseline path to FY2034-35

A Safeguard baseline is production times an applicable emissions intensity times the emissions reduction contribution — and it is that last multiplier that falls every year. It steps down by 0.049 a year to FY2029-30, and after that by whatever post-2030 decline rate is set. This facility is on the default path — it holds no trade-exposed baseline adjustment. Context

Where this facility sits

In the FY2024-25 register there are 27 facilities with the industry code Oil and gas extraction (070). The median one reported 312,681 t; this one reported 2,253,798 t, above that median. Industry code is a reporting classification, not a process description — two facilities sharing a code can run completely different plant, so treat this as orientation rather than a like-for-like comparison.

Closest by size in the same industry code: North West Shelf Project (5,750,304 t), Wheatstone Operations (4,020,667 t), APLNG Facility (2,206,497 t), Pluto LNG (1,888,110 t).
